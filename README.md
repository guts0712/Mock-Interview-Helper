# MIA - Mock Interview Analyzer

### Practice Interviews. Receive AI Feedback. Improve Confidence.

An end-to-end AI-powered interview platform built using FastAPI, PostgreSQL, Whisper, Gemini API, HTML, CSS and JavaScript.

## 🧠 How it Works

1. User creates an account.
2. Selects a job role.
3. AI generates interview questions.
4. User answers using voice.
5. Whisper converts speech to text.
6. Gemini evaluates the answers.
7. AI generates:
   - strengths
   - weaknesses
   - overall score
   - detailed feedback
